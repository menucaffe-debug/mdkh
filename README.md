# KH IL VOSTRO CAFFE — منيو واتساب

منيو إلكتروني + سلة طلب، يُرسَل الطلب كاملاً عبر **واتساب**.
**فرونت اند فقط:** لا خادم، لا قاعدة بيانات، لا مفاتيح سرّية، ولا خطوة بناء (build).

---

## 1. التشغيل

| الطريقة | كيف |
|---|---|
| **سريع** | انقر مزدوجًا على `index.html` |
| **موصى به** | النشر على GitHub Pages (القسم 4) |

> ⚠️ إذن الموقع (تحديد موقعك على الخريطة) ونسخ النص يعملان كاملًا فقط على
> **https** أو `localhost`. عند فتح الملف مباشرة (`file://`) قد يمنعهما المتصفح.

---

## 2. الإعداد الأساسي — `config.js`

```js
window.KH_CONFIG = {
    WHATSAPP: '218916666009',   // رقم المقهى: كود الدولة بدون +
    CURRENCY: 'د.ل'
};
```

- `WHATSAPP` بصيغة `218916666009` (= ‎+218 91 666 6009‎) — **بدون `+` وبدون مسافات**.
- عند تغيير الرقم لاحقًا: عدّل `config.js` **و** رقم الهاتف الظاهر في `index.html`
  (العنصر `class="mft-phone"`: الرابط `tel:` والنص المعروض).

---

## 3. تعديل الأصناف

البيانات داخل `index.html`، مصفوفات التصنيفات تُدمج في `ALL` (نحو السطر 611):

```js
const ALL=[...HC,...CC,...JU,...TR,...SMSH,...MJ,...FR,...SL,...BF,...EV,...DC];
```

شكل الصنف:

```js
{ id: 'x1', ar: 'قهوة سادة', it: 'Caffè', price: 4, img: 'capp.webp' }        // سعر مفرد
{ id: 'x2', ar: 'نسكافيه',  it: 'Nescafé', prices: { small: 4, large: 6 } }   // بمقاسات
```

أسماء التصنيفات (عربي/إيطالي) وترتيبها في `config.js` → `KH_CATEGORIES` و `KH_CATEGORY_ORDER`.

## 4. النشر على GitHub Pages (مجاني)

### الخطوة 1 — أنشئ المستودع
1. افتح **https://github.com/new**
2. الاسم: `mdkh`
3. اترك **«Add a README»** غير مُفعّل (الملف موجود عندك)
4. **Create repository**

### الخطوة 2 — ارفع الملفات

**طريقة (أ) من المتصفح — الأسهل**
1. داخل المستودع: **Add file → Upload files**
2. افتح مجلد `KH-Menu-Frontend` واسحب **كل محتوياته** (الملفات، لا المجلد نفسه)
3. **Commit changes**

**طريقة (ب) من الطرفية — الأسرع**

المجلد **مُجهَّز مسبقًا كمستودع git بـ commit جاهز** — يكفي:

```powershell
cd "C:\Users\OFOQ\OneDrive\Desktop\KH-Menu-Frontend"
git remote add origin https://github.com/<اسمك>/<اسم_المستودع>.git
git push -u origin main
```

إن أردت البدء من الصفر (وتتجاهل الـ commit الجاهز):

```powershell
git init -b main
git add .
git commit -m "KH menu"
git remote add origin https://github.com/<اسمك>/<اسم_المستودع>.git
git push -u origin main
```

### الخطوة 3 — فعّل Pages
1. في المستودع: **Settings → Pages**
2. **Source:** **Deploy from a branch**
3. **Branch:** `main` / **`/ (root)`** → **Save**
4. بعد دقيقة يظهر الرابط: `https://<اسمك>.github.io/<اسم_المستودع>/`

### الخطوة 4 — حدّث رابط الموقع (مهم إن غيّرت اسم المستودع)
`index.html` يشير إلى:

```
https://menucaffe-debug.github.io/mdkh/
```

في المواضع التالية: `link rel="canonical"` · `og:url` · `og:image` · `twitter:image` · `JSON-LD`
— استبدلها إن نشرت على عنوان/مستودع آخر.
