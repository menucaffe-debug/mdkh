# KH CAFFE &amp; Car wash — منيو واتساب

موقع واحد بِ**قسمين منفصلين** يختار الزبون بينهما من صفحة الدخول:

| القسم | الملف | المحتوى |
|---|---|---|
| **صفحة الدخول** | `index.html` | بطاقتان: المقهى · غسيل السيارات |
| **المقهى** | `cafe.html` | 118 صنفًا + سلّة طلب تُرسَل عبر واتساب |
| **غسيل السيارات** | `carwash.html` | ثلاث باقات (45 / 35 / 30 د.ل) — **عرض أسعار فقط**، بلا سلّة وبلا زر طلب |

**فرونت اند فقط:** لا خادم، لا قاعدة بيانات، لا مفاتيح سرّية، ولا خطوة بناء (build).

## 2. الإعداد الأساسي — `config.js`

```js
window.KH_CONFIG = {
    WHATSAPP: '218916666009',   // رقم المقهى: كود الدولة بدون +
    CURRENCY: 'د.ل'
};
```

- `WHATSAPP` بصيغة `218916666009` (= ‎+218 91 666 6009‎) — **بدون `+` وبدون مسافات**.
- يُستخدم في: `cart.js` (سلّة المقهى). لا يقرأه `carwash.html` بعد إزالة أزرار الطلب.
- **أرقام مكتوبة يدويًا** يجب تحديثها مع الرقم أيضًا: روابط `wa.me` و`tel:` داخل
  `index.html` و`cafe.html` و`carwash.html` (التذييل + زر واتساب العائم) وJSON-LD.

## 3. تعديل منيو المقهى

البيانات داخل **`cafe.html`**، مصفوفات التصنيفات تُدمج في `ALL` (نحو السطر 611):

```js
const ALL=[...HC,...CC,...JU,...TR,...SMSH,...MJ,...FR,...SL,...BF,...EV,...DC];
```

شكل الصنف:

```js
{ id: 'x1', ar: 'قهوة سادة', it: 'Caffè', price: 4, img: 'capp.webp' }        // سعر مفرد
{ id: 'x2', ar: 'نسكافيه',  it: 'Nescafé', prices: { small: 4, large: 6 } }   // بمقاسات
```

أسماء التصنيفات (عربي/إيطالي) وترتيبها في `config.js` → `KH_CATEGORIES` و `KH_CATEGORY_ORDER`.

## 4. تعديل باقات غسيل السيارات

كل شيء داخل **`carwash.html`** — لكل باقة مكوّنات ثلاثة:

```html
<div class="cw-img">
    <svg …></svg>
    <span class="cw-tag">متسخة جدًا</span>          <!-- شارة فوق الصورة -->
</div>
<div class="cw-body">
    <h2 class="cw-n">غسيل متسخة جدًا</h2>          <!-- الاسم -->
    <div class="cw-en">Very Dirty</div>             <!-- الاسم بالإنجليزية -->
    <div class="cw-price"><b>45</b><span>د.ل</span></div>
```

- **السعر** يُكتب في `<b>`… `</b>` فقط.
- **الصور:** منطقة `.cw-img` تعرض اليوم أيقونة مؤقتة. عند وصول الصور ضع
  `<img src="اسم-الصورة.webp" alt="">` داخل `.cw-img` — التنسيق جاهز (`object-fit:cover`).
- **بلا سلّة وبلا زر طلب**: القسم عرض أسعار فقط، والتواصل يتم عبر روابط
  واتساب في التذييل وزرّ واتساب العائم.
- **الألوان** مطابقة تمامًا لصفحة المقهى ومأخوذة من الشعار —
  `pages.css` ← `:root` (لا يوجد لون منفصل للغسيل).

## 5. النشر على GitHub Pages (مجاني)

### الخطوة 1 — أنشئ المستودع
1. افتح **https://github.com/new**
2. الاسم: `mdkh`
3. اترك **«Add a README»** غير مُفعّل (الملف موجود عندك)
4. **Create repository**

### الخطوة 2 — ارفع الملفات

**طريقة (أ) من المتصفح — الأسهل**
1. داخل المستودع: **Add file → Upload files**
2. افتح مجلد `KH-Menu-Frontend` واسحب **كل محتوياته** (الملفات، لا المجلد نفسه)
3. **Commit changes**

**طريقة (ب) من الطرفية — الأسرع**

المجلد **مُجهَّز مسبقًا كمستودع git بـ commit جاهز** — يكفي:

```powershell
cd "C:\Users\OFOQ\OneDrive\Desktop\KH-Menu-Frontend"
git remote add origin https://github.com/menucaffe-debug/mdkh.git
git push -u origin main
```

### الخطوة 3 — فعّل Pages
1. في المستودع: **Settings → Pages**
2. **Source:** **Deploy from a branch**
3. **Branch:** `main` / **`/ (root)`** → **Save**
4. الرابط: `https://menucaffe-debug.github.io/mdkh/`

### الروابط المرجعية (canonical / og / JSON-LD)
